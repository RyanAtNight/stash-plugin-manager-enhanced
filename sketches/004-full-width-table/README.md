## Variant: Full-width Table

### Design stance
Treat installed plugins as an inventory, distributing information evenly across the available width.

### Key choices
- Layout: responsive table-like grid
- Interaction: click rows to reveal secondary details
- Change cost: low-to-medium; replaces cards with row markup

### Trade-offs
- Strong at: density, alignment, comparison, minimum vertical scrolling
- Weak at: least friendly and least descriptive at a glance

### Best for
Power users managing many installed plugins.
