## Variant: Two-column Dashboard

### Design stance
Use wide screens as a dashboard by placing compact plugin cards in two columns.

### Key choices
- Layout: responsive two-column card grid
- Interaction: live search and capability disclosures
- Change cost: low; primarily CSS Grid

### Trade-offs
- Strong at: using horizontal space, showing more plugins at once
- Weak at: descriptions and metadata get less horizontal room

### Best for
Large monitors where fast library scanning matters most.
