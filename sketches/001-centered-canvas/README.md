## Variant: Centered Canvas

### Design stance
Keep the familiar single-column cards, but center the working canvas and move card actions into horizontal footers.

### Key choices
- Layout: centered 1180px canvas within the post-sidebar space
- Interaction: capability disclosure and tab states
- Change cost: very low; mostly CSS and minor card markup

### Trade-offs
- Strong at: familiarity, balanced whitespace, readable descriptions
- Weak at: still vertically long

### Best for
The safest visual correction with minimal implementation risk.
