# UI council, 2026-11-03

Running record of the council polish pass (multi-model UI review loop). Updated after every round so a dropped session loses nothing.

## Decisions (Ryan, 2026-11-03)

- **Scope:** polish only. Spacing, typography, colour, icons and consistency. Keep the accepted layout: the compact header (tabs centred between title and Cards/Table + GitHub), and the existing Cards and Table structures. No moving controls between regions.
- **Bar:** 9/10 or better in every category from every judge.
- **Round cap:** 5 rounds, then stop and ask.
- **Coverage:** every view (Installed Cards, Installed Table, Browse Cards, Browse Table, Sources, Configuration) at desktop 1920×1080, laptop 1280×800 and phone 390×844. Stash is dark-only, so there is no light theme.
- **Comparisons:** the old version (previous round) and VS Code's Extensions view (official screenshots from the VS Code docs, so nothing opens on Ryan's PC).
- **Judges:** Claude Opus 5.5 and Codex GPT-6.1 Sol, read-only, high effort. Judges are not told the target score.
- **Categories:** hierarchy, typography, colour and contrast, consistency, iconography, spacing.
- **Configuration page:** keep the two-pane list/detail layout that was deployed from uncommitted main-checkout changes on 2026-09-13. Brought into this branch as commit `57cc426`; the main checkout's copy was left untouched.

## Method

- Screenshots come from a headless Chrome script (scratchpad `capture.mjs`) that sends the Stash API key only to `localhost:9999`. It hides two capture-only artefacts: another plugin's first-run dialog (Visage) and Stash's WebSocket toast, which appears because headless WebSockets can't carry the key.
- Each round: cheaper/faster judge first; once it passes, the other judge too. Fix what I agree with, commit, deploy, recapture.

## Changes per round

### Round 1 (`660d29d`)

Accepted from judges: outline row icons (GitHub, configure, delete; red only on hover), neutral disabled buttons, secondary style for Reload / Add source / Edit / Manage / Reset, Cards/Table placeholder on Configuration so the header doesn't move, 12px badges with one meaning per colour, no mid-word breaks in table headers/dates/counts, Configuration plugin name above a small Settings label, selected plugin scrolled into view, phone toolbar grid, right-aligned phone card actions, muted plugin IDs, source links underlined on hover only.

Rejected (round 1): clamping table descriptions to 3 lines (full descriptions are a listed feature); shrinking the enable switches to Stash's size (they were enlarged on purpose in `9764ba6`); changing the solid-blue active tab (part of the accepted compact header; Codex listed it as working); un-mirroring card action order (deliberate in `d9cfcb1`).

### Round 2 (`a9d9981`, `b21fa6f`)

Accepted: Installed/Browse tables keep a 1200px minimum and scroll inside their frame with Actions pinned right (instead of ten-line description towers on laptop); 12px floor for labels, headers, IDs and the Configuration note (Stash's rem is 14px, so earlier labels were 10.5px); fixed card metadata tracks; tighter card footers; phone inline label/value for short fields, plugin actions in card order on the right edge, 44px icon targets, equal-height toolbar buttons; Sources date/status columns that grow with the table; thin Configuration list scrollbar.

Rejected (round 2): none outright. Phone stacked tables now follow the card order (switch outermost on the right), which keeps the deliberate desktop mirroring.

### Round 3 (`daed3cb`)

Fixed two round-2 regressions: browsers ignore `clamp()` widths on `<col>`, so Sources spread spare width evenly and squeezed URLs; and a 12rem Installed Actions column wrapped four-control rows. Also: visible pinned-column edge, neutral-border delete icons (red on hover/focus), more readable disabled labels, 12.5px secondary text, three-across phone Browse metadata, Installed-only mirroring on phone, fading Configuration list end, wider header count spacing, tighter card footers.

Decided by Ryan (2026-11-03, after round 3 was sent to judging): the enable switch goes **last in every view**, right-aligned (settings, delete, update, GitHub, switch). Committed as `f61592c`; replaces the earlier mirrored order. Round 4 briefs must drop the "mirrored on purpose" note.

### Round 4 (`f61592c`, `dd0000f`)

From the judge: one-line Sources dates and badge pairs at laptop width, 1260px plugin-table minimum (~290px descriptions), visible pinned-column shadow, tighter cards, weight-600 names, 12px capability labels, green Enabled badge in Configuration, separated result counts, visually matched icon glyphs, less phone chrome above results, phone Configuration list with its own ~4-row height starting on a row boundary.
