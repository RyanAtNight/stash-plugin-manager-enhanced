# Plugin screenshots

Captured from the live Plugin Manager Enhanced interface on September 13, 2026.
Images are cropped to the plugin panel. Counts, versions, dates, and settings
reflect that installation at capture time.

The original images are 1987 pixels wide, cropped without resizing from a desktop
full-page capture and encoded as PNG. The browser capture source is JPEG;
PNG encoding avoids further lossy compression but does not remove source
compression artifacts.

`browse-table.png` is the refreshed README screenshot: Browse in Table layout,
sorted by **Last commit (newest)**, with the current compact header. It is
1278 × 1000 pixels, cropped without resizing from a 1600 × 1100 browser
viewport capture. It includes the first seven complete rows. Its displayed
version identifies the build captured before the documentation commit.
