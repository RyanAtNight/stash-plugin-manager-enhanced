# Plugin screenshots

Captured from the live Plugin Manager Enhanced interface on September 13, 2026.
Images are cropped to the plugin panel. Counts, versions, dates, and settings
reflect that installation at capture time.

Each image is 1987 pixels wide, cropped without resizing from a desktop
full-page capture and encoded as PNG. The browser capture source is JPEG;
PNG encoding avoids further lossy compression but does not remove source
compression artifacts.

Copy these image references into the repository's root README as needed:
