# Plugin screenshots

Captured from the live Plugin Manager Enhanced interface on November 4, 2026, after the UI council polish pass ([council notes](../council-2026-11-03.md)). Counts, versions, dates and settings reflect that installation at capture time. Each displayed version identifies the build captured before the documentation commit.

All images come from a 2200 × 1100 browser viewport and are cropped to the plugin panel (Stash's own navigation is left out).

- `installed-table.png` and `browse-table.png` are the main README screenshots, shown in that order. Both use Table layout sorted by **Last commit (newest)** and are rendered at 1278 × 500 so they show the header, toolbar and at least four complete plugin rows.
- `installed.png`, `browse.png`, `sources.png` and `configuration.png` are 1833 pixels wide, unscaled. Installed and Browse use Cards layout sorted by **Last commit (newest)**.

Copy these image references into the repository's root README as needed:
