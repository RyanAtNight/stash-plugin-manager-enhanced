# Plugin screenshots

Captured from the live Plugin Manager Enhanced interface on September 13, 2026.
Images are cropped to the plugin panel. Counts, versions, dates, and settings
reflect that installation at capture time.

The remaining original images are 1987 pixels wide, cropped without resizing from a desktop
full-page capture and encoded as PNG. The browser capture source is JPEG;
PNG encoding avoids further lossy compression but does not remove source
compression artifacts.

`installed-table.png` and `browse-table.png` are the refreshed README screenshots,
shown in that order. Both use Table layout sorted by **Last commit (newest)**.
Each is 1278 × 500 pixels, half the previous Browse screenshot's height, and
shows at least two complete plugin rows. Both were cropped from 2200 × 1100
browser viewport captures and scaled equally to fit. Their displayed version
identifies the build captured before the documentation commit.
