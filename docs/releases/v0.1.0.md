First public release of Stash Plugin Manager Enhanced.

Enhances Settings → Plugins with Installed, Browse, Sources, and Configuration views; Cards and Table layouts; search and filters; bulk package operations; source health; and editable plugin settings.

Search waits for a 250 ms pause while preserving the input and cursor, including when holding Backspace. Configuration drafts survive redraws, and overlapping plugin operations are prevented.

## Install

Add this package source in Stash Settings → Plugins, then install **Stash Plugin Manager Enhanced**:

```text
https://ryanatnight.github.io/stash-plugin-manager-enhanced/index.yml
```

Alternatively, extract `stash-plugin-manager-enhanced.zip` into its own directory under Stash's plugins directory, reload plugins, and refresh your browser. Do not install both a manual and managed copy.

The ZIP includes the AGPL-3.0-only license and a JavaScript source map containing the original sources. Source code and build instructions are available in this tagged repository. `SHA256SUMS` contains the package checksum.

## Validation and compatibility

- Automated tests and production build run before publishing.
- Live development testing was performed against the local Stash installation; see the README for its version.
- The plugin relies on Stash's settings-page DOM. Future Stash UI changes may require updates; other Stash versions and custom themes have not been exhaustively tested.

Please report issues with your Stash version, browser, and reproduction steps.
